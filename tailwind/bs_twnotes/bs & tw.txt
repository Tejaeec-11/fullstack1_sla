Bootstrap — Complete Basics & Important Classes

1. What is Bootstrap?
Bootstrap is a popular CSS framework used to build responsive and mobile-first websites quickly.

It provides ready-made:

Layout system

Responsive grid

Buttons

Forms

Cards

Navbar

Tables

Alerts

Modals

Spacing utilities

Flexbox utilities

Typography

Colors

Responsive utilities

Basic Bootstrap setup
Using CDN:

<link
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
  rel="stylesheet"
>
JavaScript bundle:

<script
  src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
</script>

3. Bootstrap Grid System ⭐⭐⭐
One of the most important Bootstrap topics.

Bootstrap uses:

Container
   ↓
Row
   ↓
Column
Basic structure
<div class="container">
    <div class="row">
        <div class="col">
            Column 1
        </div>

        <div class="col">
            Column 2
        </div>
    </div>
</div>
Bootstrap's grid is based on 12 columns.

12 columns
--------------------------------
| 3 | 3 | 3 | 3 |
--------------------------------
Example:

<div class="row">
    <div class="col-3">25%</div>
    <div class="col-3">25%</div>
    <div class="col-6">50%</div>
</div>

4. Understanding the Navbar
<div class="d-flex justify-content-between align-items-center w-100">
d-flex
Makes the parent a Flex container.

justify-content-between
Pushes the logo to the left and menu to the right.

align-items-center
Vertically centers the logo and menu.

w-100
Makes the Flex container occupy the available width.

TAILWIND CSS – COMPLETE BASIC NOTES

1. WHAT IS TAILWIND CSS?

Tailwind CSS is a utility-first CSS framework used to create modern, responsive websites and web applications.

Instead of writing separate CSS classes, Tailwind provides predefined utility classes that can be directly used inside HTML or JSX.

Example:

<div class="bg-blue-500 text-white p-5 rounded-lg">

Hello Tailwind

</div>

Here:

bg-blue-500 → Background color

text-white → Text color

p-5 → Padding

rounded-lg → Border radius

2. WHAT IS UTILITY-FIRST CSS?

Utility means a small CSS class that performs one specific styling job.

Examples:

p-4 → Padding

mt-5 → Margin top

text-center → Text alignment

text-xl → Font size

font-bold → Font weight

bg-blue-500 → Background color

rounded-lg → Border radius

shadow-lg → Box shadow

Utility-first means we build the complete UI by combining these small utility classes.

Example:

<div class="p-5 bg-white rounded-lg shadow-lg">

Student Card

</div>

Instead of creating:

.card {

padding: 20px;

background: white;

border-radius: 10px;

box-shadow: 0 10px 15px gray;

}

3. WHY DO WE USE TAILWIND CSS?

Tailwind CSS is used because:

• Faster UI development

• Responsive design is easy

• Less custom CSS

• Easy Flexbox

• Easy Grid

• Easy spacing

• Easy colors

• Easy typography

• Easy hover effects

• Easy responsive design

• Highly customizable

• Useful for React, Next.js and other frontend projects

4. TAILWIND CSS VS NORMAL CSS

Normal CSS:

.card {

width: 300px;

padding: 20px;

background: white;

border-radius: 10px;

}

HTML:

<div class="card">

Card Content

</div>

Tailwind CSS:

<div class="w-[300px] p-5 bg-white rounded-lg">

Card Content

</div>

5. TAILWIND CSS VS BOOTSTRAP

Bootstrap:

<button class="btn btn-primary">

Login

</button>

Bootstrap gives predefined component classes.

Tailwind:

<button class="bg-blue-600 text-white px-5 py-2 rounded-lg">

Login

</button>

Tailwind gives utility classes and we build the component using those utilities.

Simple difference:

Bootstrap

↓

Ready-made Components

Tailwind

↓

Utility Classes

↓

Build Your Own UI
