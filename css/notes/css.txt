What is CSS?
Full Form
CSS = Cascading Style Sheets
CSS is a stylesheet language used to control the appearance and layout of HTML elements.

HTML creates the structure of a webpage, while CSS makes the webpage beautiful, responsive, and visually attractive.

Why Do We Use CSS?
Without CSS, webpages look plain.

CSS helps us to:

Change Colors

Change Fonts

Add Backgrounds

Create Layouts

Add Animations

Make Responsive Websites

Improve User Experience (UI/UX)

    color:red;
    font-size:40px;
}

Large Red Heading
What is Cascading?
"Cascading" means flowing down according to priority.

When multiple CSS rules target the same element, the browser decides which rule should be applied based on the CSS Cascade Rules.

Example

h1{
    color:red;
}

h1{
    color:blue;
}
Output

Blue
Because the last rule overrides the first one.

CSS Box Model - Complete Notes

What is the CSS Box Model?
The CSS Box Model is the fundamental concept used to understand how every HTML element occupies space on a webpage.

Every HTML element is treated as a rectangular box by the browser.

Whether it's:

<div>

<h1>

<p>

<img>

<button>

<input>

everything is considered a box.

Why Do We Need the Box Model?
Without the Box Model:

Elements would touch each other.

No spacing between content.

Difficult to create layouts.

Poor user experience.

The Box Model helps us:

Control spacing

Add borders

Create layouts

Improve readability

Build responsive websites

What is the CSS Box Model?

What are the four parts of the Box Model?
Content

Padding

What is Margin?

Border is the visible line surrounding the content and padding.

Difference Between Padding and Margin?
Padding creates space inside the border.

The display property is one of the most important properties in CSS.

It controls how an HTML element is displayed on a webpage.

Every HTML element has a default display value assigned by the browser.

# CSS Cascading & Specificity - Complete Notes

# What is Cascading?

## Definition

The word **Cascade** means **to flow from top to bottom**.

In CSS, **Cascading** is the process the browser uses to decide **which CSS rule should be applied** when multiple CSS rules target the same HTML element.

Simply,

> **Cascading = The rule selection process used by the browser.**

---

# Why is it Called Cascading Style Sheets?

CSS consists of three words.

### Cascading

Rules are applied based on priority.

↓

### Style

Adds design to HTML.

↓

### Sheets

CSS rules are written inside style sheets.

---

# Why Do We Need Cascading?

Imagine writing two different colors for the same heading.

```css id="cas01"
h1{

color:red;

}

h1{

color:blue;

}
```

HTML

```html id="cas02"
<h1>Welcome</h1>
```

Output

```text id="cas03"
Blue
```

Because the browser follows the **Cascade Rule**.

The **last rule wins** when both selectors have the same priority.

---

# CSS Cascade Order

When multiple CSS rules target the same element, the browser follows this order.

```text id="cas04"
1. !important

↓

2. Specificity

↓

3. Source Order (Last Rule)

↓
```

The browser checks these one by one.

---

# Rule 1 - !important

Highest Priority.

Example

```css id="cas05"
h1{

color:red !important;

}

h1{

color:blue;

}
```

Output

```text id="cas06"
Red
```

Because

```text id="cas07"
!important
```

has the highest priority.

---

# Rule 2 - Specificity

If `!important` is not present,

the browser checks **Specificity**.

---

# Rule 3 - Source Order

If specificity is equal,

the browser applies the **last written rule**.

Example

```css id="cas08"
p{

color:red;

}

p{

color:green;

}
```

Output

```text id="cas09"
Green
```

In simple words,

> **Specificity tells the browser which selector has the highest priority.**

# Interview Questions

### What is Cascading?

Cascading is the process used by the browser to decide which CSS rule should be applied when multiple rules target the same element.

---

### What is Specificity?

Specificity is the selector priority system used to determine which CSS selector has the highest precedence.

---

### What is the Cascade Order?

```text id="spe23"
!important

↓

Specificity

↓

Source Order (Last Rule)
```

---

### Which selector has the highest specificity?

```text id="spe24"
Inline Style
```

---

### What is the specificity order?

```text id="spe25"
Inline

↓

ID

↓

Class

↓

Element

↓

Universal
```

---

### When does the last rule win?

When two selectors have the same specificity and no `!important` rule is applied.

---

### Which is stronger: ID or Class?

The **ID Selector** is stronger because its specificity score is **100**, while a Class Selector has a score of **10**.

---

# Summary

```text id="spe26"
✔ Cascading = Browser's rule selection process.

✔ Specificity = Selector priority calculation.

✔ Cascade Order:
!important → Specificity → Source Order.

✔ Specificity Order:
Inline → ID → Class → Element → Universal.

✔ If specificity is equal, the browser applies the last CSS rule.

✔ Understanding Cascading and Specificity helps avoid CSS conflicts in real-world projects.
```
