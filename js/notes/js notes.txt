JAVASCRIPT – BASIC NOTES

1. JAVASCRIPT BASIC

JavaScript is a programming language used to create dynamic and interactive web pages.

Basic JavaScript process:

File

↓

Folder

↓

Code

↓

JavaScript File

↓

Browser

↓

JavaScript Engine

↓

Execution

2. FILE AND FOLDER

A JavaScript project normally contains files and folders.

Example:

project/

│

├── index.html

├── script.js

└── style.css

HTML file → Structure

CSS file → Design

JavaScript file → Logic / Behaviour

3. JAVASCRIPT FILE

JavaScript code can be written in a separate .js file.

Example:

script.js

console.log("Hello JavaScript");

HTML file:

<script src="script.js"></script>

The HTML file loads the JavaScript file into the webpage.

4. BROWSER

A browser is software used to access and display websites.

Examples:

Google Chrome

Microsoft Edge

Firefox

Safari

Opera

The browser reads HTML, CSS and JavaScript and displays the webpage.

5. JAVASCRIPT ENGINE

The browser contains a JavaScript Engine.

The JavaScript Engine is responsible for understanding and executing JavaScript code.

Examples:

Chrome → V8 Engine

Edge → V8 Engine

Firefox → SpiderMonkey

Safari → JavaScriptCore

6. V8 ENGINE

V8 is Google's JavaScript Engine.

Chrome uses the V8 Engine to execute JavaScript.

Basic process:

JavaScript Code

↓

V8 Engine

↓

Execution

↓

Result

7. COMPILER

A compiler is a program that translates source code into a form that the computer can execute.

In JavaScript, modern engines use a combination of techniques such as parsing, interpretation and Just-In-Time (JIT) compilation to execute JavaScript efficiently.

Simple learning flow:

JavaScript Code

↓

JavaScript Engine

↓

Parse

↓

Compile / Execute

↓

Result

8. MEMORY AND EXECUTION

When JavaScript runs, the JavaScript Engine needs memory to store data and an execution mechanism to run the code.

Simple process:

JavaScript Code

↓

Memory

↓

Execution

↓

Result

Example:

var username = "React";

The value "React" is stored in memory and can be used during execution.

A variable is a named storage location used to store a value.

Example:

10. VARIABLE DECLARATION

Declaration means creating a variable without assigning a value.

Example:

var username;

Here:

var → Keyword

username → Variable Name

This is called variable declaration.

11. INITIALIZATION

Initialization means assigning an initial value to a variable.

Example:

var username = "React";

Here:

var username → Declaration

= "React" → Initialization / Assignment

12. ASSIGNMENT

The assignment operator is:

=

It is used to assign a value to a variable.

Example:

var username;

username = "React";

13. VARIABLE DECLARATION KEYWORDS

JavaScript has three main variable declaration keywords:

var

let

const

14. VAR

var is the traditional JavaScript variable declaration keyword.

Example:

15. LET

let was introduced in ES6.

ES6 means ECMAScript 2015.

Example:

16. CONST

const was also introduced in ES6.

const is used when the variable binding should not be reassigned.

Example:

const course = "JavaScript";

17. ES6

ES6 stands for ECMAScript 2015.

ES6 introduced many modern JavaScript features.

Important variable declarations:

var

2. WHY DO WE USE VARIABLES?

Variables are used to:

• Store data

• Reuse data

• Modify data

• Perform calculations

• Store user input

• Store application state

• Pass data between different parts of a program

Example:

let price = 500;

let quantity = 2;

let total = price * quantity;

console.log(total);

Output:

1000

3. VARIABLE DECLARATION

Declaration means creating a variable.

Example:

var username;

let city;

const course = "JavaScript";

4. VARIABLE INITIALIZATION

Initialization means assigning an initial value to a variable.

Example:

var username = "React";

Here:

var username

↓

"React"

Initial Value

6. DECLARATION + INITIALIZATION

Both can happen in one statement.

Example:

7. VARIABLE DECLARATION KEYWORDS

JavaScript has three variable declaration keywords:

var

let

const

8. VAR

var is the traditional variable declaration keyword in JavaScript.

Example:

var username = "React";

The value can be changed.

Example:

var username = "React";

username = "JavaScript";

console.log(username);

Output:

JavaScript

9. LET

let was introduced in ES6.

ES6 = ECMAScript 2015

let is used when a variable's value may need to be changed.

Example:

let city = "Chennai";

city = "Bangalore";

console.log(city);

Output:

Bangalore

10. CONST

const was introduced in ES6.

const is used when a variable binding should not be reassigned.

Example:

const course = "JavaScript";

course = "React";

This produces an error because the const variable cannot be reassigned.

11. VAR VS LET VS CONST

var:

• Traditional

• Function scoped

• Can be redeclared

• Can be reassigned

• Hoisted and initialized with undefined

let:

• Modern

• Block scoped

• Cannot be redeclared in the same scope

• Can be reassigned

• Has a Temporal Dead Zone before declaration

const:

• Modern

• Block scoped

• Cannot be redeclared in the same scope

• Cannot be reassigned

• Has a Temporal Dead Zone before declaration

• Must be initialized during declaration

12. EXAMPLE OF VAR REDECLARATION

var username = "React";

var username = "JavaScript";

console.log(username);

Output:

JavaScript

13. LET REDECLARATION

let username = "React";

let username = "JavaScript";

This produces an error in the same scope.

14. CONST REDECLARATION

const username = "React";

const username = "JavaScript";

This produces an error in the same scope.

15. REASSIGNMENT

var:

var city = "Chennai";

city = "Bangalore";

let:

let city = "Chennai";

city = "Bangalore";

const:

const city = "Chennai";

city = "Bangalore";

The const reassignment produces an error.

17. VARIABLE NAMING RULES

Rule 1:

A variable name can contain letters.

let username;

Rule 2:

A variable name can contain numbers, but it cannot start with a number.

Valid:

let user1;

Invalid:

let 1user;

Rule 3:

A variable name can contain underscore.

let user_name;

Rule 4:

A variable name can contain dollar sign.

let $price;

Rule 5:

Spaces are not allowed.

Invalid:

let user name;

Rule 6:

Reserved keywords cannot be used as variable names.

Invalid:

let var;

let let;

let const;

Rule 7:

JavaScript is case-sensitive.

username

Username

USERName

These are different names.

59. IMPORTANT const CONCEPT

const prevents reassignment of the variable binding.

Example:

};

But:

student = {

name: "Kumar"

};

This is not allowed because the const variable cannot be reassigned.

is initialized.

Flow

     ↓

JAVASCRIPT DOM — COMPLETE INTERVIEW NOTES

1. What is DOM?
DOM stands for Document Object Model. When a web page is loaded in the browser, the browser converts the HTML document into a tree-like object structure. JavaScript can use this structure to access, read, modify, add, or delete HTML elements dynamically.

In simple words, DOM is the bridge between HTML and JavaScript. HTML creates the structure of the webpage, CSS designs the webpage, and JavaScript uses the DOM to interact with and manipulate the webpage.

For example, consider the following HTML:

<html>
  <body>
    <h1>Hello</h1>
    <p>Welcome</p>
  </body>
</html>
The browser understands it as a tree:

Document
   |
  HTML
   |
  BODY
  /   \
 H1    P
Using JavaScript, we can select any of these elements and change their content, style, attributes, or behavior.

2. Why Do We Need DOM?
Without DOM, JavaScript cannot directly interact with HTML elements on a webpage. DOM allows JavaScript to dynamically change the webpage without reloading it.

Using DOM, we can:

Change text content

Change HTML content

Change CSS styles

Add new elements

Remove elements

Change attributes

Handle user events

Create interactive webpages

Validate forms

Build dynamic UI

Real-world examples include:

Login form validation

Dark mode

Dropdown menus

Modal popup

Image slider

Todo application

Add to cart

Like button

Counter application

61. DOM Interview Questions
1. What is DOM?
DOM stands for Document Object Model. It represents an HTML document as a tree of objects and allows JavaScript to dynamically access and manipulate webpage elements.

2. What is the difference between HTML and DOM?
HTML is the markup used to define the initial structure of a webpage. DOM is the object representation created by the browser from that HTML, which JavaScript can interact with dynamically.

3. What is the difference between querySelector and querySelectorAll?
querySelector() returns the first matching element, while querySelectorAll() returns all matching elements as a NodeList.

4. What is the difference between getElementById and querySelector?
getElementById() selects an element using its ID only. querySelector() supports CSS selectors and returns the first matching element.

5. What is the difference between innerHTML and textContent?
innerHTML reads or writes HTML markup, while textContent reads or writes plain text.

6. What is an Event?
An event is an action or occurrence in the browser, such as clicking, typing, submitting a form, or moving the mouse.

7. What is an Event Listener?
An Event Listener listens for a specific event and executes a callback function when that event occurs.

8. What is Event Bubbling?
Event bubbling is the propagation of an event from the target element upward through its parent elements.

9. What is Event Delegation?
Event Delegation is attaching an event listener to a parent element and handling events from its child elements using event bubbling.

10. What is preventDefault?
preventDefault() prevents the browser's default action, such as stopping a form submission from reloading the page.

11. What is the difference between Property and Attribute?
Attributes are defined in HTML, while properties represent the current state of the corresponding DOM object in JavaScript.

12. What is classList?
classList provides methods to manage CSS classes dynamically, including add(), remove(), toggle(), and contains().

JavaScript Async Programming — Callback, Promise, Async/Await, Fetch, Then & Catch

1. What is Asynchronous JavaScript?
JavaScript normally executes code line by line. But some operations take time, such as API calls, file loading, timers, database requests, and network operations. If JavaScript waits for every slow operation to finish before moving forward, the application can become unresponsive.

Asynchronous JavaScript allows time-consuming tasks to run without blocking the rest of the program. Common asynchronous concepts in JavaScript include callbacks, promises, async/await, fetch, then, and catch.

Simple flow:

Start Task
   ↓
Task Takes Time
   ↓
JavaScript Continues Other Work
   ↓
Task Completes
   ↓
Handle Result
2. Callback Function
A callback function is a function passed as an argument to another function and executed later. Callbacks are one of the earliest ways to handle asynchronous operations in JavaScript.

Callbacks are commonly used in timers, events, and older asynchronous code. The main issue with too many nested callbacks is that the code becomes difficult to read and maintain, which is often called callback hell.

Syntax
const mainFunction = (callback) => {
    callback();
};
Example
const greet = () => {
    console.log("Hello");
};

const processUser = (callback) => {
    console.log("Processing...");
    callback();
};

processUser(greet);
Output:

Processing...
Hello

    console.log("Data Loaded");

    ↓
Data Loaded
4. Callback Hell
When multiple callbacks are nested one inside another, code becomes difficult to understand.

Example:

const firstTask = (callback) => {
    setTimeout(() => {
        console.log("First Task");
        callback();
    }, 1000);
};

const secondTask = (callback) => {
    setTimeout(() => {
        console.log("Second Task");
        callback();
    }, 1000);
};

firstTask(() => {
    secondTask(() => {
        console.log("Completed");
    });
});
This nested structure is one reason Promises became popular.

5. Promise
A Promise is an object that represents the future result of an asynchronous operation. It tells us whether the operation is still waiting, completed successfully, or failed.

A Promise has three states:

Pending
   ↓
Fulfilled
   OR
Rejected
Pending → Operation is still running

Fulfilled → Operation completed successfully

Rejected → Operation failed

6. Promise Syntax
const promise = new Promise((resolve, reject) => {

    // async operation

});
resolve() is used when the operation succeeds.

reject() is used when the operation fails.

7. Simple Promise Example
const promise = new Promise((resolve, reject) => {

    const success = true;

    if (success) {
        resolve("Task Completed");
    } else {
        reject("Task Failed");
    }

});

Fetch API is a modern JavaScript Web API used to communicate with a server through HTTP requests. Frontend applications use fetch() to request data from an API, receive a response, convert the response into usable JavaScript data, and display or process that data.

Fetch API is a Promise-based Web API used to make HTTP requests from JavaScript. It is commonly used to communicate between frontend applications and backend APIs. fetch() returns a Promise that resolves to a Response object, and methods such as response.json() are used to read the response body.
