JavaScript Introduction

JavaScript is a programming language used to make websites interactive and dynamic.

JavaScript can be used for calculations, conditions, loops, functions, objects, arrays and many other programming tasks.

JavaScript Logical Examples

Logical programming helps us solve real-world programming problems using conditions, loops, operators and functions.

Logical Example 1 — Even or Odd

Check whether a number is even or odd. 


let number = 10;

if (number % 2 === 0) {
    console.log("Even Number");
} else {
    console.log("Odd Number");
}
Output: Even Number

Logical Example 2 — Positive or Negative


let number = -5;

if (number >= 0) {
    console.log("Positive Number");
} else {
    console.log("Negative Number");
}
Output: Negative Number

Logical Example 3 — Find Largest Number


let a = 20;
let b = 35;

if (a > b) {
    console.log(a);
} else {
    console.log(b);
}
Output: 35

Logical Example 4 — Voting Eligibility


let age = 20;

if (age >= 18) {
    console.log("Eligible to Vote");
} else {
    console.log("Not Eligible");
}
Output: Eligible to Vote

Logical Example 5 — Pass or Fail


let mark = 75;

if (mark >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}
Output: Pass

Logical Example 6 — Grade


let mark = 85;

if (mark >= 90) {
    console.log("A+");
} else if (mark >= 80) {
    console.log("A");
} else if (mark >= 70) {
    console.log("B");
} else {
    console.log("C");
}
Output: A

Logical Example 7 — Sum of Numbers


let sum = 0;

for (let i = 1; i <= 10; i++) {
    sum = sum + i;
}

console.log(sum);
Output: 55

Logical Example 8 — Find Even Numbers


for (let i = 1; i <= 10; i++) {

    if (i % 2 === 0) {
        console.log(i);
    }

}
Output: 2, 4, 6, 8, 10

Logical Example 9 — Find a Number


for (let i = 1; i <= 100; i++) {

    if (i === 50) {
        console.log("Found: " + i);
        break;
    }

}
Output: Found: 50

Logical Example 10 — Student Mark


let student = {
    name: "Ravi",
    mark: 85
};

if (student.mark >= 80) {
    console.log(student.name + " scored above 80");
}
Output: Ravi scored above 80

Primitive Data Types

Primitive data types store single values. The important primitive types covered here are:

  • String
  • Number
  • Boolean
  • Undefined
  • Null

1. String

A String is used to store text or characters. 


let name = "Ravi";

console.log(name);
console.log(typeof name);
Output:
Ravi
string

2. Number

Number is used to store integer and decimal values. 


let age = 25;
let price = 99.50;

console.log(age);
console.log(price);
console.log(typeof age);
Output:
25
99.5
number

3. Boolean

Boolean has only two values: true or false. 


let isStudent = true;

console.log(isStudent);
console.log(typeof isStudent);
Output:
true
boolean

4. Undefined

A variable has the value undefined when it has been declared but no value has been assigned. 


let result;

console.log(result);
console.log(typeof result);
Output:
undefined
undefined

5. Null

Null represents an intentional empty value. 


let data = null;

console.log(data);
console.log(typeof data);
Output:
null
object

Note: typeof null returns "object". This is a historical behavior of JavaScript.
