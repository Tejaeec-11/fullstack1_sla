HTML - Day 1 Notes

What is HTML?
HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create web pages. It provides the structure of a website and tells the browser how content should be displayed.

Why Do We Use HTML?
To create web pages.

To display text, images, videos, tables, and forms.

To organize content in a structured way.

To build the foundation of every website.

Real World Examples
Google Search Page

YouTube

Amazon

Facebook

Instagram

All websites use HTML as their basic structure.

How Does HTML Work?
HTML File
    ↓
Browser Reads HTML
    ↓
Creates DOM Structure
    ↓
Displays Content
Example:

<h1>Hello World</h1>
Output:

Hello World
Basic HTML Structure
Every HTML document follows a standard structure.

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Welcome to HTML</h1>
</body>
</html>
Understanding the Structure
1.
<!DOCTYPE html>
Purpose:

Tells the browser that this document uses HTML5.

Must be the first line of every HTML document.

2. Root Element
<html>
</html>
The <html> tag is called the Root Element.

Why?

Because every other HTML element is placed inside it.

Example:

<html>
    ...
</html>
3. Head Section
<head>
</head>
The head section contains information about the webpage.

Examples:

Title

Meta Tags

CSS Links

Favicon

Example:

<head>
    <title>HTML Class</title>
</head>
4. Title Tag
<title>HTML Class</title>
The title appears in the browser tab.

Output:

HTML Class
(Shown on the browser tab)

5. Body Section
<body>
</body>
The body contains all visible content displayed on the webpage.

Example:

<body>
    <h1>Hello</h1>
    <p>Welcome</p>
</body>
Root Element
Definition:

The top-most element of an HTML document.

Example:

<html>
    <head></head>
    <body></body>
</html>
Here:

html
is the Root Element.

Parent Element
Definition:

An element that contains another element.

Example:

<body>
    <h1>Hello</h1>
</body>
Here:

body
is the Parent Element.

Child Element
Definition:

An element placed inside another element.

Example:

<body>
    <h1>Hello</h1>
</body>
Here:

h1
is the Child Element of body.

Parent and Child Relationship
Example:

<html>
    <body>
        <h1>Hello</h1>
    </body>
</html>
Structure:

html
 └── body
      └── h1
html → Parent of body

body → Child of html

body → Parent of h1

h1 → Child of body

Container Elements
Definition:

Elements that can contain other elements inside them.

Examples:

<div>
    <h1>Heading</h1>
    <p>Paragraph</p>
</div>
Container Elements:

html
head
body
div
section
article
nav
header
footer
These tags can hold other tags.

Non-Container Elements
Definition:

Elements that do not contain child elements.

Examples:

<img>
<br>
<hr>
<input>
These elements are usually self-closing or do not wrap other content.

Nested Elements
Definition:

Elements placed inside another element.

Example:

<div>
    <section>
        <h1>HTML</h1>
    </section>
</div>
Structure:

div
 └── section
      └── h1
This is called Nesting.

HTML Document Tree
Example:

<html>
    <head>
        <title>HTML</title>
    </head>

    <body>
        <h1>Welcome</h1>
        <p>HTML Class</p>
    </body>
</html>
Tree Structure:

html
├── head
│    └── title
│
└── body
     ├── h1
     └── p
The browser converts HTML into this tree structure called DOM (Document Object Model).

Key Points
HTML stands for HyperText Markup Language.

HTML provides the structure of a webpage.

<html> is the Root Element.

<head> stores page information.

<body> stores visible content.

Parent elements contain child elements.

Child elements exist inside parent elements.

Container elements can contain other elements.

Nested elements create a tree structure.

Browser converts HTML into a DOM Tree.

1. Block Level Elements

A block-level element always starts on a new line and occupies the full available width.

HTML Semantic Tags and Non-Semantic Tags

What is a Semantic Tag?
The word Semantic means "Meaning".

Semantic tags clearly describe the purpose of the content inside them.

When developers, browsers, search engines, and screen readers see a semantic tag, they can easily understand what kind of content it contains.

Why Do We Use Semantic Tags?
Before HTML5
Developers mostly used:

<div>
<div>
<div>
<div>
Everything was built using div tags.

Problem:

Difficult to understand the structure.

Poor readability.

Less SEO friendly.

Accessibility issues.

After HTML5
Semantic tags were introduced.

Example:

<header>
<nav></nav>
</header>

<main>
    <section>
        <article></article>
    </section>
</main>

<footer></footer>
Now the structure itself explains the content.

Benefits of Semantic Tags
1. Better Readability
Developers can easily understand the code.

2. Better SEO
Search engines understand the webpage structure better.

3. Better Accessibility
Screen readers can identify page sections correctly.

4. Easier Maintenance
Large projects become easier to manage.

HTML Attributes - Detailed Notes

What is an Attribute?
An Attribute provides additional information about an HTML element.

Attributes are always written inside the opening tag.

Syntax
<tagname attribute="value">
    Content
</tagname>
Example
<a href="https://google.com">
    Google
</a>
Here:

href = Attribute Name

https://google.com = Attribute Value
Structure of an Attribute
<img src="image.jpg" alt="Student Image">
Breakdown:

src          → Attribute Name

image.jpg    → Attribute Value

alt          → Attribute Name

Student Image → Attribute Value
Why Do We Use Attributes?
Attributes provide extra information to HTML elements.

Without Attributes:

<img>
Browser doesn't know:

Which image?
Where is the image?
With Attributes:

<img src="student.jpg">
Browser knows which image to display.

Types of Attributes
HTML Attributes are mainly divided into:

2. Local (Element Specific) Attributes

1. What is ?
Definition
<!DOCTYPE html> is called the Document Type Declaration.

Before HTML5, browsers used different rendering modes.

Old browser behavior is used

HTML5 and CSS behave correctly

Same output across modern browsers
